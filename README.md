## 🚀 Overview

"Hello Pale Blue Dot" is a landing page designed for a technology and programming podcast.

Initially built in January 2020 as a foundational bootcamp project, it has been completely refactored (v4.0.0) to implement modern web development practices, focusing on optimized asset delivery, scalable styling architecture, and Core Web Vitals.

## ✨ Key Features

* **Responsive Design:** Fully adaptable layout powered by Bootstrap 5.
* **Web Performance:** Adaptive image loading using `<picture>` tags with `.avif` formats to reduce bandwidth.
* **Maintainable Styling:** A clean SCSS architecture utilizing global CSS variables and native font-display optimization.
* **Semantic Structure:** Improved accessibility and SEO through semantic HTML5 tags and descriptive metadata.

## 🛠️ Technologies

* **Core:** HTML5, CSS3
* **Preprocessors:** Sass (SCSS)
* **Frameworks:** Bootstrap 5
* **Assets:** FontAwesome, optimized AVIF/PNG media
* **Version Control:** Git (Following *Conventional Commits* & *SemVer*)

## 🏃‍♂️ Getting Started

To view or modify the project locally:

1. Clone the repository:

```bash
git clone https://github.com/poved4/podcast_channel.git
```

2. Navigate to the project directory:

```bash
cd podcast-channel
```

3. Open `index.html` in your browser, or use a local server extension (like Live Server in VS Code).
